# ربات دانلودر تلگرام (بدون VPS)

این پروژه یک ربات پایتونی است که لینک عمومی ویدئو را از چند سرویس پشتیبانی‌شده می‌گیرد و فایل را در تلگرام ارسال می‌کند. برای اجرا از سرویس میزبانی ابری مثل Railway استفاده می‌شود؛ VPS شخصی لازم نیست، اما ممکن است پس از پایان اعتبار/سهمیهٔ رایگان سرویس، هزینه داشته باشد.

## امکانات
- دستورهای `/start` و `/help`
- دانلود از YouTube، Instagram، TikTok، X/Twitter، Facebook، Reddit، Vimeo و چند سایت دیگر که در `bot.py` فهرست شده‌اند
- محدودیت حجم پیش‌فرض ۴۵ مگابایت برای سازگاری با ارسال فایل در تلگرام
- محدودیت زمان دانلود و رد کردن دامنه‌های ناشناخته
- دستور `/stats` برای مدیر، در صورت تنظیم `ADMIN_ID`

## راه‌اندازی در تلگرام
1. در تلگرام به `@BotFather` پیام بده.
2. دستور `/newbot` را بفرست و نام و username ربات را انتخاب کن.
3. توکن را کپی کن. توکن مثل رمز عبور است؛ آن را برای کسی نفرست و در مخزن عمومی قرار نده.

## استقرار روی Railway (بدون VPS)
1. وارد Railway شو و یک پروژهٔ جدید بساز.
2. یک مخزن GitHub جدید بساز و فایل‌های همین پوشه را در آن بارگذاری کن. می‌توانی ZIP را از حالت فشرده خارج کنی و فایل‌ها را آپلود کنی.
3. در Railway گزینهٔ Deploy from GitHub Repo را بزن و مخزن را انتخاب کن.
4. در سرویس Railway بخش Variables این متغیرها را اضافه کن:
   - `BOT_TOKEN` = توکن BotFather
   - `ADMIN_ID` = شناسه عددی تلگرام خودت (اختیاری)
   - `MAX_MB` = `45` (اختیاری)
5. Railway به‌خاطر وجود `Dockerfile`، کانتینر را می‌سازد و اجرا می‌کند. این پروژه از long polling استفاده می‌کند و به دامنه یا webhook نیاز ندارد.
6. لاگ‌ها را بررسی کن؛ باید پیام `Starting Telegram downloader bot with polling` را ببینی.
7. در تلگرام رباتت را باز کن و `/start` بفرست. سپس یک لینک عمومی و مجاز را آزمایش کن.

## تست محلی (اختیاری)
Python 3.12 و FFmpeg لازم است. وابستگی‌ها را نصب کن:

```bash
pip install -r requirements.txt
```

متغیر `BOT_TOKEN` را در محیط تنظیم کن و اجرا کن:

```bash
python bot.py
```

## نکته‌ها و محدودیت‌ها
- سرویس‌های میزبانی رایگان ممکن است محدودیت زمان اجرا، RAM، شبکه یا سهمیه داشته باشند؛ «بدون VPS» به معنی تضمین میزبانی رایگان و دائمی نیست.
- بعضی سایت‌ها به دلیل تغییرات فنی، محدودیت منطقه‌ای، نیاز به ورود یا محدودیت ضدربات ممکن است دانلود نشوند. کوکی یا اطلاعات ورود حساب خود را به ربات نده.
- دانلود محتوای خصوصی، محتوای دارای DRM یا محتوایی که اجازهٔ دریافت آن را نداری پشتیبانی نمی‌شود.
- فایل‌های حجیم‌تر از حد تنظیم‌شده ارسال نمی‌شوند. فضای موقت پس از هر درخواست پاک می‌شود.
- برای به‌روزرسانی `yt-dlp`، تغییرات را آزمایش و نسخهٔ پروژه را دوباره Deploy کن.
- اگر توکن لو رفت، در BotFather آن را revoke کن و توکن جدید را در متغیرهای Railway قرار بده.
